Workflow Operations

The five order activities are simulated. Watch saved workflow events and real worker recovery. How Temporal works

Start or view an order

An activity does one piece of work. Each timer is a saved wait after that activity. Changing these inputs affects a new workflow only.

Temporal saves events. After a worker stops, it uses those events to rebuild progress (replay). Saved activity results are reused. Unfinished activities may retry, so real payment or stock calls must safely handle the same request again.
